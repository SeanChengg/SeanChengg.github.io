## 🎯 Quick Method: Search in Layers Panel

1. **Open Layers panel** (left sidebar)
2. **Press `Cmd + F`** (Mac) or `Ctrl + F` (Windows)
3. **Type part of the text** you want to find
4. **Click the highlighted layer**
5. **Double-click the text** on canvas to edit

**No ungrouping needed!** Text is always editable.

## 🖼️ Finding Images (Without Ungrouping)

### Method 1: Click on Image → Check Fill Panel
1. **Click the image** you see on the canvas
2. **Look at right panel** → **Fill section**
3. **You'll see image thumbnail**
4. **Click thumbnail** → **Replace image**

### Method 2: Search in Layers Panel
Look for frames with these names:
- **Left image (office scene):** `"683c37998875d9729ed4f057_Screenshot..."`
- **Right image (woman with headphones):** `"68885b655fa417bc7b845b9b_Screenshot..."`
- **Service card images:** `"683c3c70cdebe0a37ae2416c_Screenshot..."`

### Method 3: Look for Image Fills
1. **In Layers panel**, look for frames with **image icon** (small picture)
2. **Click the frame**
3. **Right panel** → **Fill** → **Replace image**

## 🎨 Step-by-Step: Edit Any Text

1. **Press `Cmd + F`** (or `Ctrl + F`) in Layers panel
2. **Type part of the text** (e.g., "invisible")
3. **Figma highlights** matching layers
4. **Click the highlighted layer**
5. **Double-click the text** on canvas (or press `T` key)
6. **Edit the text**
7. **Press `Esc`** when done

**That's it!** No ungrouping needed.

---

## 🖼️ Step-by-Step: Replace Any Image

1. **Click the image** on the canvas
2. **Check right panel** → **Fill section**
3. **See image thumbnail?** → Click it → **Replace image**
4. **Select your new image** from computer
5. **Done!**

**No ungrouping needed!**

## 💡 Pro Tips

### ✅ DO:
- Use **`Cmd + F`** to search for text
- **Double-click text** to edit directly
- **Click image** → **Fill panel** → **Replace**
- **Lock layers** you don't want to move (`Cmd + L`)

### ❌ DON'T:
- Don't ungroup everything
- Don't delete groups without checking
- Don't flatten layers
